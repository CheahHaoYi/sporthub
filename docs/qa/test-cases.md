# Test cases

The canonical case catalogue is maintained in [`docs/quality-engineering/test-cases/`](../quality-engineering/test-cases/README.md), with implementation status and source/test links in the [requirements-to-tests matrix](../quality-engineering/requirements-to-tests.md).

Use those detailed cases rather than copying them into a second list here. Cases marked **Blocked** or **Schema-only** are not end-to-end coverage; they identify missing service/API behavior or a database-only guard.
