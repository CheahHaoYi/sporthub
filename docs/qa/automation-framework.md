# Automation framework

`qa/automation` is an independent Java 21 Maven project. TestNG discovers suite tests; REST Assured sends real HTTP requests; Selenium drives a real Chrome browser through WebDriverManager and is headless by default. Set `SYSTEM_BASE_URL` (default `http://localhost:8080`), `UI_BASE_URL` (default `http://localhost:5173`) and `BROWSER_HEADLESS` (default `true`). Start the backend from the [runbook](../quality-engineering/11-learn-by-doing.md) before API checks. The current Spring Boot health endpoint is public, while `/v3/api-docs` is protected by default security.

Run `mvn test` from `qa/automation`; use `-Dgroups=api`, `-Dgroups=ui`, `-Dgroups=smoke` or `-Dgroups=sanity`. The two API tests assert health status 200/`UP` and default OpenAPI-route 401. Three Selenium tests assert required login inputs, client-side under-age registration rejection, and a customer redirect from `/admin`. These are smoke/sanity checks of existing server/UI behavior, not account registration or full commerce journeys. The old `/facilities` smoke check was removed because there is no backend facility route. Full UI journeys require backend APIs and synthetic account/data fixtures that do not exist yet. Reports are written to `target/surefire-reports/`.
