# Traceability matrix

The single maintained matrix is [`docs/quality-engineering/requirements-to-tests.md`](../quality-engineering/requirements-to-tests.md). It maps confirmed behavior and risks to cases, source and automated evidence, and labels missing server behavior as blocked. Keep updates there to avoid competing coverage claims.

Requirement statements and unresolved product decisions are in [`docs/requirements/`](../requirements/functional-requirements.md); items marked **Needs confirmation** should not be treated as acceptance criteria until agreed.
