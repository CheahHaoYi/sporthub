# Catalog, cart and checkout test cases

| ID / scenario | Goal and risk | Preconditions / data | Steps | Expected result / assertion meaning | Layer, evidence and status |
|---|---|---|---|---|---|
| EC-01 Browse active products | Avoid returning inactive or incomplete product catalogue data. | One active product exists. | Request product list. | Active product fields are returned. | API/system; Blocked: product route absent. |
| EC-02 Add valid product quantity | Prevent incorrect cart quantity or line total. | Product has stock at least 2; quantity 2. | Add to cart. | Cart shows quantity 2 and server-calculated line total. | API/integration; Blocked: cart/product service absent. |
| EC-03 Zero or negative quantity | Reject quantities that could corrupt cart and inventory state. | Active product; quantity 0 or -1. | Submit add/update request. | Validation error; no cart line is persisted. | API negative / boundary; Blocked. |
| EC-04 Out-of-stock product | Prevent overselling and negative stock. | Product stock 0 or requested quantity exceeds stock. | Attempt checkout. | Clear rejection; stock remains non-negative and no order is confirmed. | Integration/API; Blocked: inventory/checkout services absent. |
| EC-05 Valid coupon | Apply only eligible coupon discounts. | Coupon active, current time in range, subtotal meets minimum. | Apply coupon to cart. | Coupon is accepted and discount is calculated on server. | Decision table / API; Blocked: coupon/cart services absent. |
| EC-06 Expired coupon | Reject expired coupons without changing totals. | Coupon validity end is before current time. | Apply coupon. | Coupon rejected with stable error code; total unchanged. | API negative / boundary; Blocked. |
| EC-07 Invalid coupon | Reject unknown coupon codes without changing totals. | No coupon with submitted code. | Apply coupon. | Not-found/validation error per contract; total unchanged. | API negative; Blocked. |
| EC-08 Ineligible child discount | Avoid applying child pricing to an adult profile. | Adult profile added to booking cart. | Preview/checkout. | No child discount is applied; backend uses appointment-date age. | Integration/API; Pricing classification is implemented; cart/checkout integration blocked. |
| EC-09 Empty cart checkout | Prevent creation of empty orders or payment records. | Active cart has no items. | Submit checkout. | Checkout rejected; no order/payment/stock changes. | API/integration; Blocked: checkout service absent. |
| EC-10 Payment failure rollback | Prevent partial order/stock/coupon writes after payment failure. | Cart has booking/product; payment simulator set to failure. | Submit checkout. | No partial order, booking confirmation, stock decrement or coupon redemption remains. | Transaction integration; Spring/Postgres rollback primitive is tested; checkout rollback blocked. |
| EC-11 Idempotent retry | Prevent duplicate orders when checkout is retried. | Same customer sends same checkout key and request twice. | Repeat checkout after timeout. | One order is created and same result is returned. | API/integration/concurrency; Schema has a unique key; checkout service absent. |
| EC-12 Cart summary displays server totals | Catch UI display regressions in API-provided totals. | API mock returns item/discount totals. | Render cart page. | UI shows line, coupon and total values from response. This assertion is limited to the named test boundary. | React component test; Implemented in `Pages.test.tsx` (API mocked). |
